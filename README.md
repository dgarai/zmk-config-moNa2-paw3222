# moNa2 PAW3222 ZMK Firmware

ZMK firmware configuration for **moNa2: Right-Hand Trackball Version**.

This version uses the **PAW3222** optical sensor for trackball input.

## Features

- ZMK firmware
- 42 keys
- Low-profile design
- Fully wireless
- 17 mm key pitch
- 25 mm trackball
- LED indicators
- Rear magnets
- PAW3222 trackball sensor

## DYA Studio（レベル2）

[DYA Studio](https://studio.dya.cormoran.works) で、ブラウザからキーマップ・マクロ・コンボ・トラックボール・BLE 接続などを変更できる。

- ZMK 本体は Custom Studio Protocol 対応の [cormoran/zmk `main+dya`](https://github.com/cormoran/zmk/tree/main+dya)（Zephyr 4.1）。実験的な fork なので、壊れたら旧構成のファームに戻す
- 右手側を USB でつなぎ、Chrome / Edge で開いて「USB」を選ぶ（Bluetooth 接続も可）
- Trackball タブで変更できるのは、runtime input processor の部分（感度・回転・反転・スクロール量・スナップ・オートマウス）だけ。初期値は旧構成と同じ向き・量に合わせてある（`boards/shields/mona2/mona2_r.overlay`）
- **センサー固有の設定（CPI・省電力など）は未対応表示になる。** PAW3222 用の DYA Studio 対応ドライバが無く、sekigon 版ドライバを使っているため。CPI は overlay の `res-cpi` で決める
- オートマウス（MOUSE レイヤー 4 へ自動切り替え、500ms で解除）も Trackball タブで変更できる。旧構成にあった「100 カウント動いてから入る」しきい値は無くなった（gohanda11 の threshold-temp-layer が ZMK main でビルドできないため）。微小な揺れで MOUSE レイヤーに入るようなら、Trackball タブの設定で調整する
- Studio で変えた内容はキーボード本体に保存され、このリポジトリの `config/mona2.keymap` には戻らない
- 旧構成から書き換えた直後は、左右とも `settings_reset` を書き込んでから新しいファームを書き込む（BLE ペアリングは消える）

## キーマップ同期

`config/mona2.keymap` は自動生成ファイル。マスターは
[dgarai/zmk-config-moNa2-v2](https://github.com/dgarai/zmk-config-moNa2-v2) の
`config/mona2.keymap`。**キーマップを変えたいときはマスターを編集する。**
このリポジトリを編集しても次の同期で上書きされる。

詳細と元に戻す手順は [KEYMAP-SYNC.md](KEYMAP-SYNC.md) を参照。
